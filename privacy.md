# Privacy Policy — RoninResearch

**Last updated:** 2026-07-12

RoninResearch is a personal research application operated by the individual owner of this repository for private workshop use (agent tooling, API access, and research automation).

## What we collect
- This project does **not** operate a public multi-user service.
- API credentials and OAuth tokens used with third-party platforms (e.g. X) are stored **only on the operator’s machines** (or their chosen secret storage), not sold or shared with third parties for marketing.

## How data is used
- Research and automation for the operator only.
- No advertising, no sale of personal data, no analytics product built on user data from this app.

## Third-party services
- When the operator connects services such as the X API, those services process data under **their** privacy policies.
- The operator is responsible for complying with each platform’s rules.

## Contact
Questions: open an issue on this repository or contact the repository owner via GitHub.

This document exists to satisfy application registration requirements for developer APIs used by RoninResearch.
